# Support

## Getting Help

- **Documentation**: [docs/index.md](docs/index.md)
- **Issues**: [GitHub Issues](https://github.com/Akastella/oss-paper-ci/issues)

## What to include in issues

- oss-paper-ci version (`oss-paper-ci version`)
- Python version
- Operating system
- Command that failed
- Error message or unexpected output
- Expected behavior

## Scope

This tool checks reproducibility *readiness* of scientific repositories.
It does not:

- Verify scientific correctness
- Run peer review
- Guarantee reproduction success
- Provide consulting on research methods

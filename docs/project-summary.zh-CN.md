# 项目简介

OSS-Paper-CI 是一个命令行工具集，用于检查、尝试、打包和解释科研代码仓库的复现证据。

## 背景

科研论文越来越依赖代码、数据和计算环境。审稿人、读者和作者需要实用的方式来评估仓库是否可复现。手动复现既耗时又容易出错。现有的 CI 工具检查语法和测试，但不涉及复现特有的问题，如环境文件、数据文档和执行证据。

## 做了什么

OSS-Paper-CI 提供了一种结构化、自动化的复现证据方法：

- **准备度扫描**：对仓库的环境、数据、实验、结果和元数据进行评分
- **安全复现尝试**：默认以 dry-run 模式运行，记录会发生什么而不执行代码
- **复现胶囊**：将所有证据打包为可验证、可归档的压缩包，带有完整性校验
- **复现摘要**：为作者、审稿人和维护者生成可读的摘要
- **批量扫描**：通过单一配置检查多个项目
- **多语言生态检测**：支持 Python、R、Julia、MATLAB/Octave、Node、Rust、Java、C/C++、Snakemake、Nextflow、Make 和 shell
- **终端工作台**：编排多个分析步骤并显示进度

## 安全边界

OSS-Paper-CI 记录和解释复现证据。它不证明科学正确性，不判断论文质量，不预测录用概率。运行任何代码需要 `--execute` 标志。危险命令会被阻止。每个操作都有可配置的超时时间。

## 为什么重要

复现是一个光谱，不是二元的。OSS-Paper-CI 通过让复现证据可见、结构化和可操作，帮助科研社区在这个光谱上前进。低分不意味着论文有问题——它意味着仓库可以从更好的文档和打包中受益。工具产生的证据可以帮作者改进仓库，帮审稿人评估复现准备度。

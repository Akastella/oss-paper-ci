# Benchmark Fixture Matrix

The fixture matrix shows expected scores and statuses for each test
fixture.  It helps verify that scoring behavior is consistent across
releases.

## Generating the Matrix

```bash
# Markdown format
python scripts/generate_fixture_matrix.py --format markdown --output examples/benchmark/fixture_matrix.md

# JSON format
python scripts/generate_fixture_matrix.py --format json --output examples/benchmark/fixture_matrix.json
```

## Fixtures

| Fixture | Language | Expected Status | Description |
|---------|----------|-----------------|-------------|
| minimal_bad_repo | Python | fail | Minimal repo with almost nothing |
| broken_paper_repo | Python | fail | Paper repo with broken structure |
| paper_ready_repo | Python | pass | Well-structured paper repo |
| realistic_ml_repo | Python | warn | Realistic ML project |
| r_ready_repo | R | pass | R-based paper repo |
| julia_ready_repo | Julia | pass | Julia-based paper repo |
| matlab_minimal_repo | MATLAB | pass | MATLAB-based paper repo |
| make_snakemake_repo | Python/Snakemake | warn | Snakemake workflow repo |
| demo-paper-repo | Python | pass | Example paper repo |

## Interpreting Results

- **pass**: Score >= 85, no blocking findings
- **warn**: Score 50-84, or has important findings
- **fail**: Score < 50, or has blocking findings

The matrix is generated by running `oss-paper-ci scan` against each
fixture with the `default` profile and recording the results.

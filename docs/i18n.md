# Internationalization

OSS-Paper-CI provides multilingual README files for wider accessibility.

## Available Languages

| Language | File | Description |
|----------|------|-------------|
| English | [README.md](../README.md) | Primary documentation |
| 简体中文 | [README.zh-CN.md](../README.zh-CN.md) | Simplified Chinese |
| 日本語 | [README.ja.md](../README.ja.md) | Japanese |

## Translation Principles

1. **Natural language** — Not machine-translated. Written by humans for humans.
2. **Technical accuracy** — Commands and technical terms remain consistent.
3. **Cultural adaptation** — Examples and explanations adapted for the target audience.
4. **No overclaiming** — Safety warnings and limitations preserved in all languages.
5. **Consistent terminology** — Key terms translated consistently across documents.

## Consistency Checks

Run the i18n consistency checker:

```bash
python scripts/check_i18n_readmes.py
```

This checks:
- All language versions exist
- Language links are present
- Core commands are consistent
- Safety warnings are present
- No overclaiming language

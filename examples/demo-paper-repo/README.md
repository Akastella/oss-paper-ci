# Demo Paper Repository

A minimal example of a scientific paper repository with reproducibility assets.
This is a toy project for demonstrating oss-paper-ci, not a real research project.

## Setup

```bash
pip install -r requirements.txt
```

## Reproduce

```bash
python scripts/train.py
python scripts/evaluate.py
python scripts/make_figures.py
```

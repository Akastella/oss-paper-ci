# Reproduction Session Examples

This directory contains example reports generated by the `session` commands.

## Files

- `session_report_demo.md` — Markdown session report
- `session_report_demo.json` — JSON session report
- `session_report_demo.html` — HTML session report (self-contained)
- `session_resume_dry_run.md` — Resume dry-run report
- `session_rerun_failed_dry_run.md` — Re-run failed dry-run report
- `session_bundle_inspect.md` — Bundle inspection report
- `session_bundle_verify.md` — Bundle verification report

## Regenerating Examples

```bash
oss-paper-ci session start examples/repro-system-demo --name demo --output-dir .oss-paper-ci-sessions/demo
oss-paper-ci session report .oss-paper-ci-sessions/demo --format markdown --output examples/session/session_report_demo.md
oss-paper-ci session report .oss-paper-ci-sessions/demo --format json --output examples/session/session_report_demo.json
oss-paper-ci session report .oss-paper-ci-sessions/demo --format html --output examples/session/session_report_demo.html
oss-paper-ci session resume .oss-paper-ci-sessions/demo --format markdown --output examples/session/session_resume_dry_run.md
oss-paper-ci session rerun-failed .oss-paper-ci-sessions/demo --format markdown --output examples/session/session_rerun_failed_dry_run.md
oss-paper-ci session bundle .oss-paper-ci-sessions/demo --output .tmp-session-evidence.zip
oss-paper-ci session inspect .tmp-session-evidence.zip --format markdown --output examples/session/session_bundle_inspect.md
oss-paper-ci session verify-bundle .tmp-session-evidence.zip --format markdown --output examples/session/session_bundle_verify.md
```

## Important Notes

- All reports are generated from local test fixtures (no network access).
- Session commands are dry-run by default; use `--execute` to run.
- Candidate configs must be reviewed before execution.

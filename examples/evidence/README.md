# Evidence Report Examples

This directory contains example evidence reports generated by `oss-paper-ci evidence`.

## Files

- `reviewer_report.md` — Reviewer-focused Markdown report
- `reviewer_report.json` — Reviewer-focused JSON report
- `reviewer_report.html` — Reviewer-focused HTML report (self-contained)
- `author_report.md` — Author-focused Markdown report
- `maintainer_report.md` — Maintainer-focused Markdown report
- `evidence_bundle_inspect.md` — Bundle inspection output
- `evidence_bundle_verify.md` — Bundle verification output

## Generating These Examples

```bash
# Reviewer reports
oss-paper-ci evidence examples/demo-paper-repo --profile reviewer --format markdown --output examples/evidence/reviewer_report.md
oss-paper-ci evidence examples/demo-paper-repo --profile reviewer --format json --output examples/evidence/reviewer_report.json
oss-paper-ci evidence examples/demo-paper-repo --profile reviewer --format html --output examples/evidence/reviewer_report.html

# Author report
oss-paper-ci evidence examples/demo-paper-repo --profile author --format markdown --output examples/evidence/author_report.md

# Maintainer report
oss-paper-ci evidence examples/demo-paper-repo --profile maintainer --format markdown --output examples/evidence/maintainer_report.md

# Bundle
oss-paper-ci evidence bundle examples/demo-paper-repo --output .tmp-evidence-bundle.zip
oss-paper-ci evidence inspect .tmp-evidence-bundle.zip --format markdown --output examples/evidence/evidence_bundle_inspect.md
oss-paper-ci evidence verify .tmp-evidence-bundle.zip --format markdown --output examples/evidence/evidence_bundle_verify.md
```

## Limitations

- These reports are generated from synthetic test fixtures
- They demonstrate report structure, not real-world findings
- The evidence report does not prove scientific correctness
- See [docs/evidence-limitations.md](../../docs/evidence-limitations.md) for details

# Matrix Examples

This directory contains example reports generated by the `matrix` commands.

## Files

- `matrix_plan_demo.md` — Matrix plan with Python version variants
- `matrix_report_demo.md` — Matrix execution report
- `matrix_compare_demo.md` — Matrix variant comparison

## Regenerating Examples

```bash
oss-paper-ci matrix plan examples/repro-system-demo --python 3.10,3.11,3.12 --format markdown --output examples/matrix/matrix_plan_demo.md
oss-paper-ci matrix run examples/repro-system-demo --python 3.10,3.11,3.12 --format markdown --output examples/matrix/matrix_report_demo.md
oss-paper-ci matrix compare .oss-paper-ci-matrix --format markdown --output examples/matrix/matrix_compare_demo.md
```

## Important Notes

- Matrix does not auto-install Python versions.
- Missing runtimes are marked as unavailable.
- Matrix run is dry-run by default; use `--execute` to run.

## How to Generate

```bash
# Author dossier
oss-paper-ci dossier --scan-report report.json --audience author

# Reviewer dossier in Japanese
oss-paper-ci dossier --scan-report report.json --audience reviewer --language ja

# GitHub issue checklist
oss-paper-ci dossier --scan-report report.json --format issue --output issue.md
```

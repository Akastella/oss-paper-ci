# Repository Intake & Autoplan Examples

This directory contains example reports generated by the `intake` and `autoplan` commands.

## Files

- `python_intake_report.md` -- Markdown intake report for a Python ML repository
- `python_intake_report.json` -- JSON intake report for the same repository
- `python_candidate_reproducibility.yml` -- Candidate reproducibility.yml generated by autoplan
- `notebook_intake_report.md` -- Intake report for a repository with Jupyter notebooks
- `make_snakemake_intake_report.md` -- Intake report for a Make/Snakemake repository
- `github_url_dry_run.md` -- Intake report showing GitHub URL handling (no clone)
- `paper_url_boundary.md` -- Intake report showing paper URL boundary handling
- `autoplan_diff.md` -- Diff between existing and candidate reproducibility configs

## Regenerating Examples

```bash
oss-paper-ci intake tests/fixtures/intake_python_repo --format markdown --output examples/intake/python_intake_report.md
oss-paper-ci intake tests/fixtures/intake_python_repo --format json --output examples/intake/python_intake_report.json
oss-paper-ci autoplan tests/fixtures/intake_python_repo --output examples/intake/python_candidate_reproducibility.yml
oss-paper-ci intake tests/fixtures/intake_notebook_repo --format markdown --output examples/intake/notebook_intake_report.md
oss-paper-ci intake tests/fixtures/intake_make_repo --format markdown --output examples/intake/make_snakemake_intake_report.md
oss-paper-ci intake https://github.com/owner/repo --format markdown --output examples/intake/github_url_dry_run.md
oss-paper-ci intake https://arxiv.org/abs/2401.00001 --format markdown --output examples/intake/paper_url_boundary.md
oss-paper-ci autoplan diff --old tests/fixtures/intake_existing_reproducibility_repo/reproducibility.yml --new examples/intake/python_candidate_reproducibility.yml --format markdown --output examples/intake/autoplan_diff.md
```

## Important Notes

- All reports are generated from local test fixtures (no network access).
- GitHub URL and paper URL examples show boundary handling (no actual cloning).
- Candidate configs must be reviewed before use.
- Confidence scores indicate detection quality, not scientific correctness.
